# 🌤️ React Weather App

A simple and user-friendly Weather App built using **React** and the **OpenWeather API**. This application provides real-time weather data for any city worldwide.

---

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Displays temperature, humidity, and weather conditions
- 🌤️ Dynamic weather icons based on weather conditions
- 📱 Responsive design for all devices

---

## 🛠️ Technologies Used

- **React.js** - Frontend library
- **OpenWeather API** - For fetching weather data
- **Axios** - For API requests
- **CSS/Material UI** - Styling

---
